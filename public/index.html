Your level in each topic

Every topic has its own ladder: Beginner, then Intermediate, then Advanced. Finish a built stage and you can really do the thing — not just read about it.

Kafka

Beginner: Send three fake orders into one cluster so messages wait in a line. (Kafka)
Intermediate: Watch the copy tool (MirrorMaker 2) copy orders to a second cluster. (Kafka)
Advanced: Fix a stopped mirror — find the bad port, watch the missing order appear on the second cluster. (Kafka)

PostgreSQL

Beginner: Run a main database with one standby copy. (PostgreSQL)
Intermediate: Switch to the standby copy with the failover tool (Patroni). (PostgreSQL)
Advanced: Kill the database on purpose, bring it back like on-call work. (PostgreSQL)

Redis

Beginner: Use a fast memory store for counts and queues. (Redis)
Intermediate: Test reading data from a read-only copy. (Redis)
Advanced: Fix Redis out of memory — set a clean-up rule (eviction policy). (Redis)

Object Store

Beginner: Save fake receipts into one file store. (Object Store)
Intermediate: Watch a mirror copy receipts to a second store. (Object Store)
Advanced: Fix a stopped mirror — start it again, count both sides. (Object Store)

Load Balancer

Beginner: Put one guard in front of three backends. (Load Balancer)
Intermediate: Kill one backend, check the site stays up. (Load Balancer)
Advanced: Break a backend or config on purpose, fix it like on-call work. (Load Balancer)

Docker & Containers

Beginner: Install Docker, check your machine, run your first container. (Lesson 0, Zero-Cost Lab)
Intermediate: Run a tiny web server in a box, stop and start it. (Zero-Cost Lab)
Advanced: Fix a container that starts then stops. (Zero-Cost Lab)

Kubernetes

Beginner: Learn pods, services, and deploys on a small cluster. (Kubernetes)
Intermediate: Scale the app 1 to 3 copies and swap its version. (Kubernetes)
Advanced: Fix a pod stuck crashing — find the wrong database name. (Kubernetes)

Linux, Git & CI/CD

Beginner: Save work online with Git and write a first script. (Lesson 0, Zero-Cost Lab)
Intermediate: Make saving work run a check by itself, show pass or fail. (Zero-Cost Lab)
Advanced: Fix a broken script and a failed check. (Zero-Cost Lab)

Whole System & On-Call

Beginner: See how data moves, copies itself, survives a crash. (Start Here, Start Here)
Intermediate: Trace one fake order through web, queue, database, file store. (End-to-End)
Advanced: Break the order pipeline — stop the worker, watch it catch up. (End-to-End)

Career & Proof

Beginner: Answer real support interview questions in plain words. (Interview Pack)
Intermediate: Build three small portfolio projects as proof. (Portfolio)
Advanced: Turn finished projects into honest, simple resume bullets. (Resume Bullets)
