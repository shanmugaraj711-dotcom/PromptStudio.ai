Your level in each topic

Every topic has its own ladder: Beginner, then Intermediate, then Advanced. Finish a built stage and you can really do the thing — not just read about it. A stage marked “Coming next” has no lesson so far; we say so honestly.

Kafka

Beginner: Send three fake orders into one cluster so messages wait in a line. (Kafka)
You can: Send fake orders into a Kafka cluster and see them arrive in order.
Intermediate: Watch MirrorMaker 2 copy those orders to a second cluster. (Kafka)
You can: Watch MirrorMaker 2 copy orders from one Kafka cluster to a second cluster.
Advanced: Fix the mirror when it stops copying — find the bad port, fix it, watch the lag drop to zero. (Kafka)
You can: Fix a broken Kafka mirror and prove the orders caught up.
Advanced challenge: Mirror stopped copying — find the bad port, fix it, watch the lag drop to zero.

PostgreSQL

Beginner: Run one main database alongside one standby copy. (PostgreSQL)
You can: Run a main PostgreSQL database paired with a standby copy.
Intermediate: Switch over to the standby copy — first by hand, then with Patroni — with no data lost. (PostgreSQL)
You can: Fail over from main to standby by hand and with Patroni without losing data.
Advanced: Kill the database on purpose and bring it back up like on-call work. (PostgreSQL)
You can: Recover a PostgreSQL database after killing it on purpose.
Advanced challenge: Database will not restart after a crash — remove the stale lock file, start it, check it answers.

Redis

Beginner: Use a fast memory store for counts, queues, and short-lived values. (Redis)
You can: Store and read counts, queues, and short-lived values in Redis.
Intermediate: Test reading data from a read-only copy. (Redis)
You can: Test reading data from a read-only Redis copy.
Advanced: Fix Redis when it says out of memory — set an eviction rule and a limit, write again. (Redis)
You can: Fix a Redis that refuses new writes and prove writing works again.
Advanced challenge: Redis says out of memory — set an eviction rule and a limit, write again.

Object Store

Beginner: Save fake receipts into one file store. (Object Store)
You can: Put fake receipt files into an object store.
Intermediate: Watch a mirror copy those receipts to a second file store. (Object Store)
You can: Verify that a mirror copies those files to a second object store.
Advanced: Fix the mirror when it stops copying — start it again, sync, count both sides. (Object Store)
You can: Restore missing files from the mirror copy.
Advanced challenge: Mirror stopped copying receipts — start it again, sync, count both sides.

Load Balancer

Beginner: Put one guard in front of three backends. (Load Balancer)
You can: Place one load balancer guard in front of three backend servers.
Intermediate: Kill one backend and verify that the site stays up. (Load Balancer)
You can: Kill one backend and verify the site still answers traffic.
Advanced: Stop a backend or break a config on purpose and fix it like on-call work. (Load Balancer)
You can: Bring a stopped backend back and fix a broken config during an on-call drill.
Advanced challenge: 502 Bad Gateway — find the wrong port in nginx.conf, check, reload, see 200 OK.
