About this simulation

Practice version of the Zero-Cost Lab — One Machine, No Cloud Bill lab. It shows the lab’s real outputs, but nothing here runs a live service. Every command is real syntax — but it only echoes fixed output, so it cannot hang or fail.

What it does: You do not need a cloud account or a bill to learn this — one machine is enough. This practice terminal runs a small website in a container, then writes a little script that checks on it.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

Your proof: Save the script's answer: "Running containers:" and "my-site is Up". It proves your site runs and your script can see it.

Done. Now run the real lab with Docker — the same commands, on your own machine. That is where the learning sticks.
