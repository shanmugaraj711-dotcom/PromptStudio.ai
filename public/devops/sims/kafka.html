About this simulation

Practice version of the Kafka Lab — Messages in a Line lab. It shows the lab’s real outputs, but nothing here runs a live service. Every command is real syntax — but it only echoes fixed output, so it cannot hang or fail.

What it does: Two small Kafka clusters on your own machine. Send three fake orders into the first one, read them back, then watch MirrorMaker 2 copy them to the second one. All data is fake.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

Your proof: Save the mirrored messages: read them back on cluster b and save the output to proof/kafka-mirror.txt. It proves the copy works.

Done. Now run the real lab with Docker — the same commands, on your own machine. That is where the learning sticks.
