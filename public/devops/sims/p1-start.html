About this simulation

Practice version of the Start Here — Phase 1: The Data Tier lab. It shows the lab’s real outputs, but nothing here runs a live service. Every command is real syntax — but it only echoes fixed output, so it cannot hang or fail.

What it does: Phase 1 is one small shop: messages in a line, a database, a fast memory store, a file cupboard, and one door in front. This practice terminal knocks on each of the five doors, one at a time, so you can see every part answer.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

Your proof: Save the five answers: PONG, the 3-row table, the topic list, the bucket list, and the Hostname line. Together they prove the whole data tier is up.

Done. Now run the real lab with Docker — the same commands, on your own machine. That is where the learning sticks.
