About this simulation

Practice version of the End-to-End Lab — One Fake Order, All the Way Through lab. It mimics the lab’s real outputs in your browser, so you can practise the commands on your phone. Nothing real runs or installs here.

The real lab: A small order pipeline, all on one machine. A fake order file lands in a folder. A program stores the file, sends the order to Kafka, and another program saves it in PostgreSQL and updates a counter in Redis. A load balancer spreads visitors across three backends. Then you kill the main database and watch the standby take over — and a new order still flows through.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

Your proof: Save the proof: the 6-row orders table and the counter at 6, after the worker caught up. It proves the whole pipeline survives a dead database — and a stopped worker.

After you finish: run the real lab with Docker on your computer — the same commands, on your own machine. That is where the learning sticks.
