About this simulation

Practice version of the Redis Lab — A Fast Memory Store lab. It mimics the lab’s real outputs in your browser, so you can practise the commands on your phone. Nothing real runs or installs here.

The real lab: Two Redis stores on your own machine: a main one and a copy that follows it. Save fake values, set expiry times, use a counter, and see what happens when you try to write to the copy. Outputs below are from a real run on a server, step by step.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

After you finish: Two-way idea, in plain words: what if two stores both accept writes at the same time? Then they must merge the changes. That merge rule is called a CRDT. It is a paid feature. The free Redis in this lab does not have it. One-way copy is free and simple; two-way copy is a paid feature with rules you must understand first.

Your proof: Save the promotion proof: the INFO replication output showing role:master, plus the counter value. It proves the copy can take over.

After you finish: run the real lab with Docker on your computer — the same commands, on your own machine. That is where the learning sticks.
