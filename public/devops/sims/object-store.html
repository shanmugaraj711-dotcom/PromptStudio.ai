About this simulation

Practice version of the Object Store Lab — A File Cupboard lab. It shows the lab’s real outputs, but nothing here runs a live service. Every command is real syntax — but it only echoes fixed output, so it cannot hang or fail.

What it does: Two file stores on your own machine with Moto — a free S3-compatible stand-in. Put fake receipt files into the first store and watch them appear in the second store by themselves. All files are fake.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

Done. Now run the real lab with Docker — the same commands, on your own machine. That is where the learning sticks.
