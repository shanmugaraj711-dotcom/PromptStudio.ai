About this simulation

Practice version of the Load Balancer Lab — One Guard, Three Backends lab. It shows the lab’s real outputs, but nothing here runs a live service. Every command is real syntax — but it only echoes fixed output, so it cannot hang or fail.

What it does: Three small backends and one NGINX load balancer in front of them. Ask the load balancer for the page six times and see a different backend answer each time. Then kill one backend and watch the site stay up.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

Your proof: Save the proof: the curl loop output with web2 missing. It proves the site stays up with a backend down.

Done. Now run the real lab with Docker — the same commands, on your own machine. That is where the learning sticks.
