About this simulation

Practice version of the Start Here — Phase 2: Linux, Git, Docker and More lab. It mimics the lab’s real outputs in your browser, so you can practise the commands on your phone. Nothing real runs or installs here.

The real lab: Phase 2 is the rest of the toolkit: the base skills and the tools that run real systems. This practice terminal checks the five tools you need are all here, by asking each one its version.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

Your proof: Save the five version lines. If every tool answers, your machine is ready for Phase 2.

After you finish: run the real lab with Docker on your computer — the same commands, on your own machine. That is where the learning sticks.
