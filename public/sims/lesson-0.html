About this simulation

Practice version of the Lesson 0: Before the Terminal lab. It mimics the lab’s real outputs in your browser, so you can practise the commands on your phone. Nothing real runs or installs here.

The real lab: A terminal is just a window where you type what you want the computer to do, and Docker is the free program that runs the labs for you. This practice terminal lets you check Docker is there, then run the one script that checks your whole machine.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

Your proof: Save the last line of the check script: "All OK - your machine is ready for the labs." It proves your machine can run the labs.

After you finish: run the real lab with Docker on your computer — the same commands, on your own machine. That is where the learning sticks.
