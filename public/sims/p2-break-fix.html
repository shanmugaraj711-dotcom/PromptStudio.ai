About this simulation

Practice version of the Break-and-Fix Labs — Learn Like On-Call Work lab. It mimics the lab’s real outputs in your browser, so you can practise the commands on your phone. Nothing real runs or installs here.

The real lab: On-call work is mostly this: something breaks, you read the message, you fix the one thing that is wrong. This practice terminal breaks six small things on purpose, and you fix each one.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

Your proof: Save the six fixes: the right image name, a container that stays up, a test file that exists, a merged file, an open door, and a Dockerfile that copies a file that is really there.

After you finish: run the real lab with Docker on your computer — the same commands, on your own machine. That is where the learning sticks.
