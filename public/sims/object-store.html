About this simulation

Practice version of the Object Store Lab — A File Cupboard lab. It mimics the lab’s real outputs in your browser, so you can practise the commands on your phone. Nothing real runs or installs here.

The real lab: Two file stores on your own machine with Moto — a free S3-compatible stand-in. Put fake receipt files into the first store and watch them appear in the second store by themselves. All files are fake.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

Your proof: Save the proof: the file listed in both stores — moto-a and moto-b. It proves the mirror copies by itself.

After you finish: run the real lab with Docker on your computer — the same commands, on your own machine. That is where the learning sticks.
