About this simulation

Practice version of the Cheat Sheets — Commands You Will Actually Use lab. It mimics the lab’s real outputs in your browser, so you can practise the commands on your phone. Nothing real runs or installs here.

The real lab: A cheat sheet is only useful if your hands know the commands, not just your eyes. This practice terminal runs the most-used commands from the sheets against a real practice state, so you can see what each one answers.

What it does NOT do: it does not run a live service, it does not hold real data, and it does not touch your machine beyond this tab.

Your proof: Save the answers: disk and memory, the containers, the pod, the clean Git state, the main store, and the empty file store. One page of commands, all answered.

After you finish: run the real lab with Docker on your computer — the same commands, on your own machine. That is where the learning sticks.
