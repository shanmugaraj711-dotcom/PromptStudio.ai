About this simulation

This is the practice version of the lesson. Everything runs in your browser tab — no install, no server, works on your phone.

What it is: Git is the tool every developer and DevOps engineer uses to save versions of their work, undo mistakes and work in a team. In this practice terminal you create a repository, make commits, branch off safely, and merge back.

What it does NOT do: it does not touch your computer or run any real service. It teaches the commands; to build the habit, repeat them on your own machine.

Your proof: Save the output of git log. It proves you made real commits.
